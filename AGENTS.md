# Trabalho neste repositório

Leia `README.md`, `docs/DEVELOPMENT.md` e `docs/CONTINUITY.md` antes de alterar o comportamento.

- Mantenha a extensão pequena e use as dependências existentes.
- Preserve a saída automática, o final `_join.pdf`, a ordem alfabética e a proteção contra sobrescrita.
- Não execute comandos de shell construídos com nomes de arquivos.
- Use PDFs sintéticos nos testes e capturas; não inclua documentos pessoais, credenciais ou dados de outras aplicações.
- Execute `python3 -m unittest -v`, `sh -n install.sh uninstall.sh` e `git diff --check` antes de concluir mudanças.
- Instalação local e código versionado são cópias distintas. Use `./install.sh` para sincronizar.
- Atualize a documentação e o registro de continuidade quando houver mudança de comportamento ou distribuição.
